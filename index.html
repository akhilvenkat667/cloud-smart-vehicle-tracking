Cloud characteristics demonstrated (NIST)

  • On-demand self-service — a new vehicle registers itself just by writing to /vehicles; no admin needed.
  • Broad network access — the dashboard works from any browser, devices connect over Wi-Fi and the internet.
  • Resource pooling — Firebase’s multi-tenant backend stores this project alongside millions of others.
  • Rapid elasticity — one vehicle or a hundred, the same code and no scaling work.
  • Measured service — Spark free tier with usage quotas; cost rises only if usage grows.
Why this is a cloud computing project: the vehicle, the database and the user are in three different places, connected only through the internet. All storage, synchronization and delivery happen in Google’s cloud — the project itself runs no server of its own. Deploying the dashboard to Firebase Hosting (see README) makes even the web delivery a cloud service.
